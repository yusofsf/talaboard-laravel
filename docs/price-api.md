# API قیمت لحظه‌ای

این API آخرین قیمت‌های ثبت‌شده برای طلا، نقره، سکه، دلار و انس را برمی‌گرداند. پاسخ معمولاً از آخرین اسنپ‌شات قیمت خوانده می‌شود؛ اگر هنوز اسنپ‌شاتی ثبت نشده باشد، سرویس قیمت به‌صورت زنده اطلاعات را دریافت می‌کند.

## ساخت اعتبار

1. با حساب ادمین وارد پنل شوید.
2. در «مدیریت» → «تنظیمات» → «API قیمت لحظه‌ای»، یک نام کاربری انگلیسی وارد کنید.
3. دکمهٔ «ثبت نام کاربری و ساخت سکرت» را بزنید.
4. سکرت نمایش‌داده‌شده را در محل امن ذخیره کنید.

سکرت فقط یک بار نمایش داده می‌شود و نسخهٔ هش‌شدهٔ آن در دیتابیس می‌ماند. ساخت سکرت جدید، سکرت قبلی را بی‌درنگ باطل می‌کند.

## درخواست

```http
GET https://metalsp.ir/api/v1/prices
Authorization: Basic <base64(username:secret)>
Accept: application/json
```

احراز هویت از نوع HTTP Basic است. API را فقط از طریق HTTPS فراخوانی کنید؛ ارسال Basic Auth روی HTTP ناامن است.

### cURL

```bash
curl --user "YOUR_USERNAME:YOUR_SECRET" \
  --header "Accept: application/json" \
  https://metalsp.ir/api/v1/prices
```

### JavaScript (سرور Node.js)

```js
const username = process.env.METALSP_API_USERNAME;
const secret = process.env.METALSP_API_SECRET;
const authorization = `Basic ${Buffer.from(`${username}:${secret}`).toString('base64')}`;

const response = await fetch('https://metalsp.ir/api/v1/prices', {
  headers: { Accept: 'application/json', Authorization: authorization },
});

if (!response.ok) throw new Error(`Price API failed: ${response.status}`);
const prices = await response.json();
```

## پاسخ موفق

کد پاسخ `200 OK` است. مقادیر قیمت به تومان هستند، مگر انس که دلار آمریکا است. مقدار `null` یعنی منبع آن قیمت در دسترس نبوده است.

```json
{
  "gold": {
    "mithqal": 32500000,
    "geram": 7500000,
    "bahar": 85000000,
    "nim": 45000000,
    "rob": 27500000
  },
  "gold_buy": {
    "mithqal": 32300000,
    "geram": 7450000,
    "bahar": 84000000,
    "nim": 44000000,
    "rob": 26500000
  },
  "silver": {
    "mithqal_999": 600000,
    "gram_999": 138500,
    "mithqal_995": 595000,
    "gram_995": 137000
  },
  "silver_buy": {
    "mithqal_999": 580000,
    "gram_999": 134000,
    "mithqal_995": 575000,
    "gram_995": 133000
  },
  "dollar": { "price": 95000, "label": "دلار آمریکا" },
  "ounce": { "gold": 2350.5, "silver": 31.2 },
  "open": { "gold.geram": 7480000 },
  "errors": [],
  "updated_at": "12:34:56"
}
```

| فیلد | توضیح |
|---|---|
| `gold` / `gold_buy` | قیمت فروش و خرید طلا و سکه. `mithqal` مثقال آب‌شده، `geram` گرم طلا، و `bahar`/`nim`/`rob` سکهٔ تمام/نیم/ربع هستند. |
| `silver` / `silver_buy` | قیمت فروش و خرید نقره با عیار ۹۹۹ و ۹۹۵؛ کلیدهای `gram_*` گرم و `mithqal_*` مثقال‌اند. |
| `dollar.price` | قیمت فروش دلار آمریکا به تومان. |
| `ounce.gold` / `ounce.silver` | قیمت انس طلا و نقره به دلار آمریکا. |
| `open` | اولین قیمت غیرخالی ثبت‌شده در همان روز تهران؛ برای محاسبهٔ تغییرات روزانه استفاده می‌شود. |
| `errors` | خطاهای منابع بالادستی در زمان ساخت اسنپ‌شات. وجود خطا لزوماً کل پاسخ را نامعتبر نمی‌کند. |
| `updated_at` | زمان به‌روزرسانی به وقت تهران (`HH:mm:ss`). |

### قطعی منبع قیمت طلا

اگر منبع بالادستی قیمت طلا (Talaland) در دسترس نباشد، بخشهای `gold` و `gold_buy` در پاسخ با آخرین مقادیر ثبتشدهی همان اقلام پر میشوند تا تابلوی قیمت و مصرفکنندههای API بدون قیمت نمانند. در زمان قطعی منبع، این مقادیر «آخرین قیمت ثبتشده» هستند نه قیمت لحظهای زنده؛ فقط کلیدهای `null` پر میشوند (انس طلا/نقره هم اگر همهی منابعش در دسترس نباشند از آخرین مقدار ثبتشده پر میشود) و بخشهای نقره و دلار منابع و fallback مستقل خود را دارند.

## خطاها و محدودیت

| کد | دلیل |
|---|---|
| `401 Unauthorized` | نام کاربری یا سکرت نامعتبر/ارسال‌نشده است. پاسخ هدر `WWW-Authenticate` دارد. |
| `429 Too Many Requests` | بیش از ۶۰ درخواست در یک دقیقه از یک کلاینت ارسال شده است. |
| `503` یا `500` | خطای موقت سرویس یا زیرساخت؛ با backoff دوباره تلاش کنید. |

هر کلاینت حداکثر ۶۰ درخواست در دقیقه می‌تواند بفرستد. برای مصرف مداوم، پاسخ را در سرویس خود کش کنید و سکرت را فقط در متغیر محیطی یا secret manager نگه دارید؛ هرگز آن را در کد فرانت‌اند یا مخزن Git قرار ندهید.
